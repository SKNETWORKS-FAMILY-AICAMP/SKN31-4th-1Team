# 화면 설계서



## 1. 사이트맵 (라우트 기준)

```
/                     메인(랜딩)                              SCR-01
/guide                이용 가이드                              SCR-02
/reference             데이터 출처                              SCR-03
/privacy                개인정보처리방침                          SCR-04
/prompt                 AI 치매 상담 (로그인 필요)                 SCR-10, SCR-11
/prevention              예방 탭
  ├─ 오늘의 대화 위젯 (로그인 시에만 상단 노출)                    SCR-27, SCR-28
  ├─ 오늘의 추천 + 게시글 목록(카테고리 필터)                     SCR-12
  └─ 두뇌 게임 슬라이더                                          SCR-14
/posts, /post/:id         게시글 목록/상세                        SCR-12, SCR-13
/center-search             치매 센터 찾기 (지도, 비로그인도 가능)     SCR-25, SCR-26
/profile                    계정 정보 (로그인 필요)                  SCR-08, SCR-09
/game/sudoku                스도쿠                                 SCR-15, SCR-16
/game/color-match             색깔 맞추기                            SCR-17, SCR-18
/game/sequence                순서 기억하기                          SCR-19, SCR-20
/game/card-match                카드 짝 맞추기                        SCR-21, SCR-22
/game-stats                       두뇌 게임 통계                       SCR-23, SCR-24

(전역) 로그인/회원가입 모달, 로그인 상태 드롭다운                 SCR-05, SCR-06, SCR-07
```

`/prompt`와 `/game/*`는 자체 헤더를 쓰므로 전역 헤더(`Header.jsx`)가 숨겨진다
(`App.jsx`의 `hideGlobalHeader` 조건).

### 2-2. 신규 화면 — 치매 센터 찾기 (SCR-25~26)

구현 파일: `dementia_front/src/pages/CenterSearchPage.jsx` +
`src/components/centerSearch/*`. 상세 레이아웃 목업은
[`mds/center_map_guide.md`](../mds/center_map_guide.md) 1절 참고.

| 코드 | 화면명 | 설명 | 주요 요소 |
|---|---|---|---|
| SCR-25 | 치매 센터 찾기 - 검색 전 | `/center-search` 진입 시 기본 화면. 전국 313곳이 지도에 클러스터로 표시되고, 좌측 패널엔 검색 안내만 표시된다. | 지도(전국 클러스터), 주소 검색 버튼, 현재 위치 버튼, 시도/시군구 드롭다운, 반경 선택(5/10/20km), 프로그램 태그 필터 |
| SCR-26 | 치매 센터 찾기 - 검색 결과 | 주소/현재위치/지역 검색 후. 검색 좌표 마커+반경 원, 반경 내 센터 개별 마커, 좌측에 거리순 리스트. 마커·리스트 클릭 시 센터 상세 오버레이(주소·전화·프로그램·길찾기) | 검색 위치 마커, 반경 원, 센터 마커(광역센터/예방프로그램 보유 센터 구분), 결과 리스트 카드, 상세 오버레이 |

**상태 분기**: 지도 SDK 로딩 실패 시에도 좌측 리스트(정적 JSON 기반)는 계속 동작한다
— 지도만 "지도를 불러오지 못했습니다 + 다시 시도" 카드로 대체.

### 2-3. 신규 화면 — 오늘의 대화 (데일리 체크인) (SCR-27~28)

구현 파일: `dementia_front/src/components/dailyCheckin/*`,
`src/hooks/useDailyCheckin.js`<br>
**로그인 사용자에게만 노출**(예방 탭 최상단, "오늘의 추천" 섹션 위).

| 코드 | 화면명 | 설명 | 주요 요소 |
|---|---|---|---|
| SCR-27 | 오늘의 대화 위젯 | 예방 탭 상단 카드. 오늘 체크인 여부에 따라 4가지 상태(로딩/미완료/완료/오류)로 전환 | 미완료: "아직 오늘의 체크를 하지 않으셨어요!" + 시작 버튼<br>완료: "오늘의 체크를 완료했어요!" + tone 칩(안심/보통/관찰 권함/상담 권유) + 요약 1~2줄 |
| SCR-28 | 오늘의 대화 모달 | 위젯 클릭 시 열리는 대화 모달. AI와 텍스트로 주고받고, "대화 마치기"로 종료 | 말풍선 대화창, 입력창, 대화 마치기 버튼, 완료 시 체크마크 전환 프레임(자동 종료) |

**대화 내역 초기화**: 서버에 원문을 저장하지 않으므로, 모달을 열 때마다(같은 날 재시도
포함) 항상 새 대화로 시작한다.

## 3. 반응형 기준

기존 화면(SCR-01~24)은 Tailwind 표준 브레이크포인트를 따른다. 4차 신규 화면은 다음
기준을 추가로 지킨다.

| 화면 | `lg`(1024px+) | `sm`(~640px) |
|---|---|---|
| SCR-25/26 (지도) | 지도 전체 배경 + 좌측 플로팅 패널(380px) | 지도 상단 55% + 검색·결과 하단 45% 분할(패널이 지도를 가리지 않음) |
| SCR-27/28 (오늘의 대화) | 예방 탭 폭(`max-w-4xl`)에 맞춘 카드/모달 | 모달 `max-w-lg` 유지, 여백만 축소 |

## 4. 접근성 공통 기준

모든 화면(기존+신규)에 적용:
- 본문 `text-base`(16px) 이상, 클릭 대상 44×44px 이상
- 색상만으로 상태를 구분하지 않고 텍스트 라벨 병행 (예: 지도 마커 범례, tone 칩)
- 명도 대비 4.5:1 이상
